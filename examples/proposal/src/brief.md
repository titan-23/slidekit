# 資料作成フローの提案

この例は、資料を作る担当者へ、内容の整理から配布までの進め方を説明する資料である。
発表時間は約 3 分、枚数は表紙を含めて 4 枚とする。

- 内容と表示の検討事項を二列で示す。
- 作成時間と確認時間を分け、簡単な数式で合計時間を説明する。
- 数式は説明用の仮定であり、測定結果ではないことをノートに残す。
- 図、矢印、数式を PowerPoint 上で編集できる形で出力する。
- 標準表示と数式の互換画像の両方を確認する。
- スライドに句点を使わず、ノートは「です・ます」調とする。

元資料と外部素材は使わない。式は、一枚当たりの作成時間と確認時間が一定という仮定から導く。
文字サイズの自動縮小は使わない。意味の区切りで行を分ける箇所だけ改行を指定する。
初回生成後の修正は原則 3 回までとし、残る問題は完成扱いにせず報告する。
